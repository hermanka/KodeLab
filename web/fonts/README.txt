Locally hosted open-license fonts used by KodeLab, following DESIGN.md.

Mona Sans (display): https://github.com/google/fonts/tree/main/ofl/monasans
Inter (UI/body): https://github.com/google/fonts/tree/main/ofl/inter
IBM Plex Mono (editor/code): https://github.com/google/fonts/tree/main/ofl/ibmplexmono

The accompanying OFL-*.txt files preserve each font's license and copyright notices.
The UI uses original inline SVG icons rather than proprietary Font Awesome Pro assets.
